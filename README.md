# Library Management System

A full-stack MERN Library Management System.

## Features

- Student management
- Book management
- Book issue and return
- Student registration
- Admin dashboard
- REST API
- MongoDB database
- React frontend
- Node.js and Express backend

## Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
